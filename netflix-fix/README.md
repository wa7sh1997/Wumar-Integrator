# Wumar Netflix Fix

Android diagnostic assistant for Netflix error -121.

Checks: Netflix installation/version, active network, Android network validation, VPN transport, automatic date/time and timezone, DNS resolution for www.netflix.com, HTTPS reachability, Android/device info.

Provides direct shortcuts to Android Date & Time, Wi-Fi, network, Private DNS, VPN, Netflix app settings, Play Store, and Netflix.

Normal Android apps cannot silently clear another app's data or change Private DNS/system time. The app therefore opens the official Android settings pages for the user to apply those changes.
